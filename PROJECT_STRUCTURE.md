## ?? **Authentication Flow**

### **Student Registration Flow**
```
1. Client ? POST /api/auth/register-student
   {email, password, dateOfBirth, ...}
   ?
2. AuthController.RegisterStudent()
   ?
3. AuthService.RegisterStudentAsync()
   ?? Create User (Identity)
   ?? Create Student entity
   ?? Assign "Student" role
   ?
4. TokenService.GenerateAccessTokenAsync()
   ?? Generate JWT with claims
   ?? Add StudentId to claims
   ?
5. Return AuthResponse with token
   ?
6. Client stores JWT in localStorage/sessionStorage
```

### **Login Flow**
```
1. Client ? POST /api/auth/login
   {email, password}
   ?
2. AuthController.Login()
   ?
3. AuthService.LoginAsync()
   ?? Find user by email
   ?? Validate password
   ?? Get user roles
   ?? Fetch Student/LandLord if exists
   ?
4. TokenService.GenerateAccessTokenAsync()
   ?? Create JWT with user claims
   ?? Add role-specific claims
   ?
5. Return TokenResponse
   ?
6. Client uses JWT in Authorization header
```

### **Protected Endpoint Flow**
```
1. Client ? GET /api/protected
   Headers: Authorization: Bearer {JWT}
   ?
2. JwtBearer middleware validates token
   ?? Verify signature
   ?? Check issuer/audience
   ?? Validate expiration
   ?
3. Extract claims and create ClaimsPrincipal
   ?
4. Controller receives authenticated user
   ?? Can access User.Identity.Name
   ?? Can check User.IsInRole()
   ?? Can read custom claims
   ?
5. Return response
```
